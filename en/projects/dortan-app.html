DortanApp

Town-hall activity booking desktop app backed by PostgreSQL.

View on GitHub

Overview

University WPF client for recording and filtering town-hall activity reservations against a PostgreSQL schema.

UI fields bind to the data layer so reservation lists stay in sync without manual refresh plumbing.

Features

  • Reservations · Create and filter activity bookings with date and detail fields.
  • Activity catalog · Select existing activities or add new ones before booking.
  • Auth screen · Login gate before staff reach the reservation views.
  • Figma mockup · Prototype used to lock layout before the WPF build.
