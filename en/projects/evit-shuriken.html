Evit'Shuriken

WPF ninja dodge game where shurikens force split-second movement.

View on GitHub

Overview

First-year Computer Science project: a 2D WPF game with a ninja avatar, collision checks, and a short loop from menu to game over.

Built in C#/XAML under Visual Studio; visual and sound cues mark hits and ends of runs.

Features

  • Dodge loop · Continuous shuriken spawns that demand precise keyboard movement.
  • Run states · Menu, active play, and game-over screens wired in WPF.
  • Feedback · Visual and audio cues tied to collisions and run endings.
