Helvetic Events

Event-brief platform with Clean Architecture FastAPI, React clients, and OpenAI qualification.

View live demo

Overview

Backend FastAPI service (SQLAlchemy, PostgreSQL, Alembic, Pytest) exposes domain use-cases for event briefs; client and admin SPAs are React/TypeScript with Tailwind.

Admin access uses OTP/2FA; OpenAI qualifies briefs and powers a conversational assistant. Live UI is published on Netlify.

Architecture

View the diagram
  • Decoupled Frontends · Responsive client SPA (React/TypeScript) alongside a 2FA/OTP-protected administration back-office.
  • Clean Architecture Backend · Strict separation between FastAPI routers, domain use-cases and repositories, validated with Pytest.
  • AI Qualification & Data · OpenAI integration for automated event brief qualification and PostgreSQL persistence managed with Alembic.

Features

  • Briefs and projects · Create and track event projects and briefs end to end.
  • OTP / 2FA admin · Hardened admin authentication for privileged operations.
  • AI qualification · OpenAI-assisted brief scoring and conversational help.
  • React SPAs · Client and admin TypeScript fronts with Tailwind.
  • OpenAPI docs · Swagger-published API contract for integration.
