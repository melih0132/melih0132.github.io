Shared IA

Collaborative AI chat: rooms of up to four users must agree before a prompt hits OpenAI.

View on GitHub

Overview

Node.js/Express API with Socket.io, JWT, PostgreSQL, and Swagger; React/Vite SPA with Zustand, Zod, Tailwind, and shadcn/ui.

Pending messages wait for peer validation; competing proposals resolve by vote before the OpenAI call streams back to the room.

Architecture

View the diagram
  • WebSocket Synchronization · Bidirectional Socket.io rooms broadcasting presence, typing indicators and proposal states.
  • Consensus & Conflict Resolution Engine · Server-side state machine holding OpenAI calls until members validate a prompt or resolve competing proposals by vote.
  • Persistence & Streaming · PostgreSQL room storage and real-time AI response streaming to all room participants.

Features

  • Collective validation · Peers must approve a pending message before the AI call.
  • Conflict votes · Simultaneous proposals resolved by room vote.
  • Realtime sync · Socket.io for presence, typing, and state.
  • Rooms and JWT · Invitations, auth, and OpenAI streaming under one room model.
  • React SPA · Vite, Hook Form/Zod, Zustand, shadcn/ui.
