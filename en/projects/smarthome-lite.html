SmartHome Lite

Distributed home automation: web, Android, Z-Wave edge, and ML-driven dimming.

View on GitHub

Overview

Central FastAPI service orchestrates lights, plugs, IF-THEN rules, and smart dimming; clients are a Next.js dashboard and a Kotlin/Compose Android app.

A Raspberry Pi edge node runs Flask plus Z-Wave JS UI against local sensors; PostgreSQL/TimescaleDB stores relational data and time series for Pytest-covered ML pipelines.

Architecture

View the diagram
  • Presentation & Edge IoT Layer · Next.js web dashboard and Kotlin/Compose Android app query the secured API; the Raspberry Pi node bridges local Z-Wave hardware over Flask.
  • FastAPI Orchestration · JWT authentication, Pydantic schemas, real-time IF-THEN rule evaluation and automated smart dimming.
  • Persistence & ML · Sensor time-series stored in TimescaleDB/PostgreSQL feed classification, regression and habit-clustering pipelines.

Features

  • Device dashboard · ON/OFF and brightness for lights, plug control, centralized gear view on web and mobile.
  • Presence history · Z-Wave MultiSensor events pushed to the backend for rules and charts.
  • IF-THEN engine · Rule CRUD, automatic evaluation, and predefined scenarios.
  • ML dimming · Scenario classification, intensity regression, habit clustering, ambient light adaptation.
  • Monitoring · Presence and luminance charts on the Next dashboard and Android app.
