Uber Vue/.NET

Ride-booking clone with a Vue.js SPA on an ASP.NET Core JWT API.

View on GitHub

Overview

Follow-up to the Laravel Uber project: Vue.js handles maps, booking, and account UI; ASP.NET Core exposes REST endpoints with JWT and GDPR-oriented encryption.

PostgreSQL via EF Core stores rides, drivers, and ratings; Swagger documents the API and unit tests cover core flows.

Architecture

View the diagram
  • Vue.js SPA Client · Reactive frontend handling route search, real-time geolocation tracking and booking workflows.
  • .NET Core REST API · Decoupled MVC controllers, JWT authentication, sensitive data encryption and GDPR compliance.
  • PostgreSQL Persistence · Relational modeling for rides, users and ratings with full Swagger/OpenAPI documentation.

Features

  • Geolocation · Live driver/passenger positions and map updates.
  • Payments · Encrypted payment path with security-focused handling of sensitive fields.
  • Bookings · Create, edit, and track trips with notifications.
  • Ratings · Post-ride reviews for service quality.
  • Vue SPA · Client UI for maps, filters, and account management.
