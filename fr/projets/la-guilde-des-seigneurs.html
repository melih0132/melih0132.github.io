La Guilde des Seigneurs

Monorepo Symfony séparant API REST JWT et front consommateur pour personnages, bâtiments et utilisateurs.

Voir sur GitHub

Aperçu

Projet EIP en deux apps Symfony 7.4 (api/, front/). L’API expose CRUD personnages/bâtiments/utilisateurs avec LexikJWT, voters et Nelmio OpenAPI. Le front Twig/Bootstrap stocke le JWT en session et appelle l’API via HttpClient et API_URL.

MySQL + Doctrine (migrations, fixtures), tests PHPUnit sur les deux applications. Dépôt : symfony-project.

Architecture

Voir le schéma
  • Monorepo découplé (front/ & api/) · Deux applications Symfony 7.4 indépendantes communiquant exclusivement par HTTP REST.
  • Sécurité & Contrôle d’accès · Authentification stateless par token JWT (LexikJWTAuthenticationBundle) et autorisations granulaires via Voters Symfony.
  • Contrat OpenAPI & Qualité · Documentation Swagger générée via NelmioApiDocBundle, migrations Doctrine et suite de tests PHPUnit.

Fonctionnalités

  • API REST documentée · CRUD personnages/bâtiments, pagination, filtres, Swagger Nelmio.
  • Authentification JWT · Inscription, connexion, émission de tokens pour les endpoints.
  • Front consommateur · App Symfony Twig avec session JWT et CRUD francisé.
  • Voters · Autorisation granulaire sur personnages, bâtiments et utilisateurs.
  • Doctrine et tests · Migrations, fixtures JSON, PHPUnit sur api et front.
