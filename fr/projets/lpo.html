LPO

Base PostgreSQL de comptages d’oiseaux pour la LPO, exploitée via Excel et Power BI.

Voir sur GitHub

Aperçu

Modélisation MCD puis MLD (Visual Paradigm / PowerAMC), tables PostgreSQL avec clés et contraintes, peuplement de jeux de comptage simulés. Requêtes SQL pour l’extraction ; analyses dans Excel et tableaux de bord Power BI (tendances, biodiversité, comparaisons saisonnières).

Fonctionnalités

  • MCD / MLD · Entités comptages, observateurs, espèces, sites et relations.
  • PostgreSQL · Schéma avec intégrité référentielle et données de test.
  • Excel · Stats par espèce, géographie et tendances temporelles.
  • Power BI · Tableaux de bord interactifs sur les populations.
  • Requêtes SQL · Extraction et agrégation pour l’analyse.
