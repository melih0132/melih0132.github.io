Uber Vue/.NET

Clone de transport avec géolocalisation, réservation et paiements sur une stack Vue.js et .NET Core.

Voir sur GitHub

Aperçu

SPA Vue.js pour la cartographie, la réservation et le tunnel de paiement. API ASP.NET Core (C#, MVC) avec JWT, chiffrement des données sensibles et orientation RGPD. Persistance PostgreSQL via EF Core, documentation Swagger et tests unitaires.

Version modernisée du clone Uber Laravel, côté performances et UX. Code sous big-projects/uber-dotnet-vue.

Architecture

Voir le schéma
  • Client SPA Vue.js · Interface réactive gérant la recherche d’itinéraires, le suivi géographique en temps réel et le tunnel de réservation.
  • API REST .NET Core · Contrôleurs MVC découplés, authentification JWT, chiffrement des données sensibles et conformité RGPD.
  • Persistance PostgreSQL · Modélisation relationnelle des courses, utilisateurs et évaluations documentée sous Swagger.

Fonctionnalités

  • Géolocalisation · Suivi des positions et mise à jour dynamique de la carte.
  • Paiement sécurisé · Tunnel de paiement avec chiffrement des données sensibles.
  • Trajets et réservations · Création, suivi et notifications de courses.
  • Notation · Évaluation des trajets par les utilisateurs.
  • SPA Vue.js · Interface réactive desktop et mobile.
